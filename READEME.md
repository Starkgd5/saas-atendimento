Guia Passo-a-Passo para Configurar Webhook

# 1. Acesse o Meta Developer Portal
# https://developers.facebook.com/

# 2. Crie ou selecione seu App
# - WhatsApp Business API
# - Adicione o produto WhatsApp

# 3. Configure o Webhook
# URL: https://seu-dominio.com.br/api/v1/webhook/whatsapp
# Verify Token: (mesmo do .env: WHATSAPP_VERIFY_TOKEN)

# 4. Inscreva-se nos eventos:
# - messages
# - message_deliveries
# - message_reads

# 5. Salve e teste
